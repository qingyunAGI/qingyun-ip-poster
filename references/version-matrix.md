# 版本矩阵与系列差异控制

## 通用字段

为每个版本建立内部标签：

- `poster_type`：business / keynote / guest-card / event-master / character-keyart
- `ratio`：3:4 / 9:16
- `information_density`：low / medium / high
- `subject_count`：1 / 4—8 / silhouette-group
- `scene`：演讲 / 棚拍 / 访谈 / 会议桌 / 舞台 / 角色世界观
- `shot`：超近景 / 近景 / 半身 / 3/4 身 / 全身
- `pose`：正面 / 侧面 / 思考 / 手势 / 仪式 / 圆桌
- `subject_position`：左 / 中 / 右 / 跨栏
- `layout`：上标题 / 左标题 / 二分 / 双栏 / 对称 / 大留白 / 纵向分区
- `palette`：黑绿 / 黑橙 / 黑紫 / 黑金 / 暖白墨绿 / 银白红 / 黑银红
- `emphasis`：关键词 / 数字 / 观点 / 活动日期 / 角色名

## 活动整套矩阵

### 活动总海报

固定为一张 9:16：

- 顶部：活动主题、日期、Logo。
- 中部：多人对话场景或品牌舞台。
- 下部：嘉宾矩阵。
- 底部：时间、平台与 CTA。

### 嘉宾卡

按实际嘉宾数生成 N 张 3:4，不套 5/7/10：

| 固定 | 可变 |
| --- | --- |
| 网格、字体比例、眼线、人物尺度、页脚、活动事实 | 人物、观点、强调短语、单一强调色 |

强调色可在同一受控色板中轮换，但亮度与饱和度必须统一。并排检查：

- 眼线高度偏差不超过画布高度约 3%。
- 标题起始线、姓名基线、身份行高和页脚完全对齐。
- 每张只强调一个观点，不把不同嘉宾做成不同品牌。

嘉宾超过 8 位时，把总海报拆成阵容分页；不要继续缩小姓名和身份。

双版本必须锁定：脸、发型、服装结构、武器、饰件、阵营、主色材质。允许变化：动作、镜头、背景叙事、光线和版式。

需要扩展到 5 个方向时，在双版本之外增加：

3. 武器/法器特写角色卡。
4. 阵营对峙或环境叙事版。
5. 极简收藏封面版。

## 相似度检查

任意两张若同时满足以下五项中的三项，判定过于相似并重做：

- 主体在同一侧。
- 景别相同。
- 动作或视线相同。
- 标题断行与信息分栏相同。
- 背景属于同一空间且对比关系相同。

## 系列一致性

保持：

- 同一现实人物或虚构角色身份。
- 同一主题、事实表与专业定位。
- 同一字体系统、网格与材质语言。
- 同一强调色强度和缩略图可读标准。

让差异来自视觉叙事，不来自虚构不同身份、不同活动事实或不同角色设定。
