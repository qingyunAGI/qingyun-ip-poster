# 海报交付质量检查

## 通用硬门槛

### 主体

- [ ] 现实人物与参考图是同一个人，脸型、五官、年龄感和显著特征未漂移。
- [ ] 虚构角色在不同版本中保持同一张脸、发型、服装结构、武器与阵营。
- [ ] 手、手臂、麦克风、剑、链条、盔甲、桌椅和身体比例正常。
- [ ] 深色衣服/黑甲保留暗部层次；银发/银甲在白底上仍有完整轮廓。

### 事实与文字

- [ ] 姓名、标题、身份、数字、奖项、日期、时间和地点逐字准确。
- [ ] 所有现实身份信息来自用户提供或可追溯来源。
- [ ] 没有生成用户未提供的品牌、客户、活动、Logo、麦标或奖章。
- [ ] Logo 使用原文件，未拉伸、重绘或替换。
- [ ] 断行不拆词，没有孤立标点、单字尾行或生成式乱码。

### 传播与构图

- [ ] 手机缩略图能识别主体与核心主张。
- [ ] 只有一个视觉中心、一个强调短语和一个高饱和强调色。
- [ ] 重要内容不贴边，不落入平台裁切或操作区。
- [ ] 主标题、姓名、活动名与日期没有同时争抢第一视觉。
- [ ] 去色检查后，主体、标题与背景仍能分层。

### 批量与系列

- [ ] 差异来自景别、位置、动作、场景、版式和叙事，不只是换色。
- [ ] 系列共享字体、网格、材质、事实表与强调色强度。
- [ ] 任意两张没有同时在主体位置、景别、动作、标题结构和背景中的三项相同。

## 商务个人 IP 专项

- [ ] 3—5 张参考图被正确分配为身份、体型和姿态锚点。
- [ ] 资历最多 5 条，弱信息已删除。
- [ ] 成品像商业编辑人物封面，不像课程促销模板。
- [ ] 5/7/10 张中至少有三种景别、三种姿态或场景、左中右位置变化。

## Keynote 观点专项

- [ ] 观点先于履历，控制在 2—3 行并按语义断句。
- [ ] 只强调 2—5 个字；背景巨字不承担必读信息。
- [ ] 人物脸、麦克风/手势与观点文字互不遮挡。
- [ ] 身份最多两行，没有做成人物简历。

## 嘉宾卡系列专项

- [ ] 所有卡片的眼线高度偏差不超过画布高度约 3%。
- [ ] 人物尺度、裁切、光比、标题起点、姓名基线和页脚一致。
- [ ] 每位嘉宾观点、姓名和身份来自同一份已核实资料。
- [ ] 每张只使用一个强调色，系列饱和度和亮度一致。
- [ ] 人物朝镜头或画面内侧，不无意看向画外。

## 活动总海报专项

- [ ] 9:16 缩至 10% 时仍能识别活动主题、日期时间和多人对话场景。
- [ ] 嘉宾矩阵列宽、姓名基线、身份行距一致。
- [ ] 顶部与底部重复出现的日期/时间完全一致。
- [ ] 嘉宾数量、圆桌剪影人数和阵容文案不存在误导性冲突。
- [ ] 删除侧边装饰英文、条码和星号后，核心信息仍完整。
- [ ] 嘉宾超过 8 位时已拆分页，不用极小字号硬塞。

## 创意 IP 角色专项

- [ ] 修仙符号融入结构，不是随机贴龙纹、符纸或印章。
- [ ] 机械甲能区分外壳、关节、连接件与饰件。
- [ ] 暗朱红只作 3%—7% 点睛；虹彩材质没有变成廉价彩虹塑料。
- [ ] 白版的左侧三段文案区、黑版的左右侧栏和底部区保持干净。
- [ ] 黑版面部、法器与胸甲形成清晰中轴焦点链。
- [ ] 背景神兽、烟雾和建筑只在二次阅读时出现，不抢角色。

## 交付门槛

出现以下任一问题，不应直接交付：

- 身份或角色漂移。
- 关键中文、姓名、日期、时间或 Logo 错误。
- 虚构现实信息。
- 明显肢体、器物或透视畸形。
- 缩略图无法识别核心主张。
- 重要信息落入裁切危险区。
- 系列版本高度重复或事实不一致。
